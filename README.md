# Connect-4
Connect 4 is a turn-based strategy game developed in Python using the pythonGraph graphics library. This was my first computer science project in college, created as part of an open-ended assignment where we were given the freedom to develop any piece of software of our choice. I worked alongside Ivan, Cole, and Shivam to bring this project to life. The result is an interactive version of the classic Connect 4 game, where a human player competes against a computer-controlled opponent in a visually rich environment.

The game is played on a traditional 7-column, 6-row grid. Players take turns dropping colored discs into columns with the objective of connecting four pieces in a row—either horizontally, vertically, or diagonally. The user interface is controlled through keyboard input, with the player using the left and right arrow keys to move a selection arrow across the columns and pressing the Enter key to drop a piece into the selected column. The computer opponent then takes its turn, utilizing basic AI logic to either complete a winning move, block the player from winning, or choose a random valid column if no strategic move is available.

Visual feedback is provided throughout the game to enhance the player experience. A start button initializes the game, and a clearly labeled “New Game” button allows the player to reset the board at any time. Win and loss states are visually displayed using bold on-screen messages. The game loop is managed with clean Python logic, integrating board updates, arrow controls, AI decisions, and win condition checks into a seamless gameplay experience.

Connect 4 was built entirely in Python with the help of the pythonGraph library, which we used to render the board, draw shapes, and handle user input. Running the game requires Python and the pythonGraph module. Once set up, players can launch the game and immediately begin playing using only their keyboard. This project not only introduced me to the fundamentals of programming logic, user interaction, and simple AI, but also gave me my first hands-on experience building a complete software application from the ground up.
